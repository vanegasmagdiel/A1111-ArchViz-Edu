# Guía de usuario — A1111 ArchViz v8.2 A0 STABLE

**Copyright © 2026 Dr. Magdiel Torres Vanegas.**

Ejecute únicamente `INSTALAR_A1111_ARCHVIZ.bat`.

El instalador verifica el paquete, detecta hardware, permite elegir destino, muestra perfiles, aplica el perfil correspondiente, instala desde cero, ejecuta smoke tests y abre A1111 tras PASS.

Los logs técnicos completos quedan en `_archviz_state\reports\`; la consola muestra estados resumidos.

Después de instalar use `ABRIR_A1111_ARCHVIZ.bat`.
