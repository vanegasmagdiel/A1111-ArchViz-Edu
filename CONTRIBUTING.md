# Contributing

A0 is **frozen**. Pull requests that alter the A0 functional contract are not accepted except for narrowly scoped critical hotfixes.

Educational contributions are welcome in:

- documentation and teaching examples;
- license/reference corrections;
- reproducibility checks;
- A1 Backend Capsules development;
- test fixtures that do not include restricted model weights.

## Rules

1. Preserve `Copyright © 2026 Dr. Magdiel Torres Vanegas` on original A1111 ArchViz source files.
2. Do not remove or weaken third-party notices.
3. Do not commit model weights, private credentials, API keys, local user paths, or unreviewed binaries.
4. New third-party dependencies must document source, version/pin, license, and reason for inclusion.
5. A1 work must not silently mutate the frozen A0 contract.
